# Commit Discipline Rule

When performing work that modifies 4 to 5 files (or significant changes across multiple files):
1. **Pause Work**: Stop making further edits once 4-5 files have been significantly changed.
2. **Notify User**: Inform the user about the files changed and wait for their approval.
3. **Wait for Commit & Push**: Wait until the user has committed and pushed the changes and explicitly instructs the agent to resume work.
